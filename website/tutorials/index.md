# Tutorials

The guide says what each part of unagit does. These pages go through a whole
job from start to finish, a key at a time.

| Tutorial | You will |
| --- | --- |
| [Your First Review](/tutorials/first-review) | install unagit, connect a server, review a merge request in your editor and approve it |
| [A Change Across Repositories](/tutorials/cross-repo-change) | make one branch in three repositories, commit, and open linked merge requests |
| [Waiting for a Pipeline](/tutorials/watch-a-pipeline) | watch a merge request, get on with other work, and read the failed job when it tells you |
| [Hand a Review to an Agent](/tutorials/agent-review) | prepare a review and start Claude Code in it, beside unagit |
| [Make Your Own Theme](/tutorials/own-theme) | fork a theme and change it live |

Each assumes you have read [Getting Started](/guide/), and the later ones
assume unagit is set up as in the first.

::: tip Lost in a screen?
`Alt-Enter` lists what can be done with the row under the cursor, `:` what the
screen can do, and `?` its keys. Every tutorial step can be found there by name
when its key slips your mind.
:::
